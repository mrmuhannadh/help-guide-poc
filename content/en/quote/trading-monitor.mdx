# Trading Monitor

<FigureProvider>

Trading Monitor details can be viewed via the Quote Dashboard as in Figure 1, via the Quote Dashboard under Intraday Monitor.

Window invoking options:
1. Quote Dashboard → Trading Monitor
2. Quote Dashboard → Intraday Monitor
3. Quote → Trading Monitor
4. Right-click a symbol → Trading Monitor

## Filter Details

The Trading Monitor window can be filtered by the symbol filter text box by clicking on it, and selecting or typing the required symbol.
