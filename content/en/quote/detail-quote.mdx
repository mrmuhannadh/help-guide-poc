# Detail Quote

<FigureProvider>

The Detail Quote can be viewed via the menu.

Window invoking options:
1. Quote → Detail Quote (CTRL+D)  
2. Right-click a symbol → Detail Quote  
3. Click the Search bar at the top of the application and select a symbol

## Other Windows Accessible via Detail Quote

- Time and Sales  
- Depth by Price  
- Depth by Order  
- Chart  
- Alert Summary  
- News  
- Announcements

## Filter Details

The Detail Quote window can be filtered using the symbol filter text box — click it and type or select the required symbol.
