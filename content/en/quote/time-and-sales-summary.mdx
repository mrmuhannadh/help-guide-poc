# Time and Sales Summary

<FigureProvider>

Time and Sales Summary details can be viewed via the Quote Dashboard and via the menu.

Window invoking options:
1. Quote → Time and Sales Summary (CTRL+T)  
2. Right-click a symbol → Time and Sales Summary

## Filter Details

The Time and Sales Summary window can be filtered using the symbol filter text box — click it and type or select the required symbol.
