## Add New Watch List

**STEPS**

1. Open the `My Watch` window and choose **New Watch List**.
2. Enter a name for the new watchlist.
3. Add symbols by typing the symbol name or selecting symbols in the **Add Symbols** text box.

<Figure
  baseName='my-watch/add-new-watchlist'
  alt='Pro 11 Trade My Watchlist New Watchlist'
  description='Add New watch list'
/>

## Add Conditional Watch List

**STEPS**

1. Open the `My Watch` window and choose **Conditional Watch List**.
2. Enter a name for the watchlist and select the exchanges.
3. Add symbols by typing a symbol name or selecting symbols in the **Add Symbols** text box.

<Figure
  baseName='my-watch/add-conditional-watchlist'
  alt='Pro 11 Trade My Watchlist New Conditional Watchlist'
  description='Add New Conditional watchlist'
/>

## Create Conditions for a Conditional Watch List

**STEPS**

1. After creating a conditional watchlist, click the **+ Condition** button.
2. Click **+ Condition** in the `My Watch` window to create one or more conditions.
3. The Create Condition dialog contains:
   - Name
   - Colour
   - Match All Conditions
   - Match Any Conditions

4. If you choose **Match All Conditions**, every condition must be met. If you choose **Match Any Conditions**, the watchlist will match when at least one condition is met.
