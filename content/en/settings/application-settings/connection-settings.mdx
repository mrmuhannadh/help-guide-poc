# Connection Settings

1. Click on **Settings → Application Settings** to view the **Settings** window, the following window will be displayed to the user.
2. Manage connection settings in this window.

**STEPS**

1. Under the *Connection Settings* section, change details if required.
2. By default, the **Secure** check-box will be ticked to maintain a secure connection with the servers.  
   _[Note that a secure connection will be made only if the servers support a secure connection.]_
3. Click **Apply** and then the **Save** button.
