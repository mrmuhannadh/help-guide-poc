# Table Settings

1. Click on **Settings → Application Settings** to view the **Settings** window, the following window will be displayed to the user.
2. Through the **Table Settings** section, the user can set the **Theme** and the **Scrolling speed** of tables.

## Themes

**STEPS**

a. Under the **Themes** section, the Show Border, Colour of the border, text, row, and selected cell can be applied.  
b. Click **Apply** and then the **Save** button.

## Scrolling Speed

**STEPS**

c. The scrolling speed of the table can be adjusted by using the scrolling speed slider bar.  
d. Click **Apply** and then the **Save** button.
