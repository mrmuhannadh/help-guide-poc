# Dashboard

Manage the default dashboards to be displayed in the workspace here.

## STEPS

1. Click **Settings → Application Settings** to view the **Settings** window. The following window will display to the user.

2. Under the *Predefined Dashboards* section, select from the list which dashboards to display by default.

3. Click **Select All** to select all dashboards in the list, or click **Unselect All** to remove all selections.

4. Click **Apply** and then the **Save** button.
