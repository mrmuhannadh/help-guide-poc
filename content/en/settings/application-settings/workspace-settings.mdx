# Workspace Settings

1. There are **3 sections** in the workspace settings: **Save Workspace**, **Edit Workspace**, and **Default Workspace** in the manage workspace settings.
2. Click **Settings → Application Settings** to open the **Settings window**. The following window will be displayed.

## Save Workspace

**STEPS**

1. In the Save Workspace section, there are two options: **Always Save Workspace on Exit** and **Ask Save Workspace** before exiting the application.
2. If the user selects **Always Save Workspace on Exit**, the system prompts a confirmation dialog before exiting.
3. If the user selects **Ask Save Workspace**, no confirmation dialog appears before exit.
4. After choosing an option, click **Apply**, then **Save**.

---

## Edit Workspace

**STEPS**

5. In the Edit Workspace section, there are two options: **Rename** and **Ask Delete**.
6. To rename a workspace, click the **edit icon**.
7. To delete a workspace, click the **delete icon**.
8. After making changes, click **Apply**, then **Save**.

---

## Default Workspace

**STEPS**

9. In the Default Workspace section, existing workspaces are listed in a dropdown.
10. The user can select one workspace to open automatically upon login.
11. After choosing one, click **Apply**, then **Save**.
