# Shortcut Settings

Manage shortcut settings for windows as shown below.  
By default, some windows already have assigned shortcut keys.

**STEPS**

1. Click **Settings → Application Settings** to open the **Settings** window.
2. Click **Reset To Default** to reset all shortcut configurations.
3. Use the **Filter** option in Shortcut Settings to quickly search and filter shortcuts.
