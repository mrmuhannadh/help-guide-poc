# Symbol Comparison

<FigureProvider>

Compare up to four symbols via the Symbol Comparison window. Access via the Analyze dashboard or via the Menu.

Window invoking options:
1. Analyze Dashboard → Symbol Comparison  
2. Analyze → Symbol Comparison

Compare the following details of symbols:
• Quote information  
• Performance  
• Income statement  
• Balance sheet  
• Cash flow  
• Ratios  
• Pro chart

## Compare Symbols

STEPS
1. Click the first symbol text box and enter or select a symbol to compare.  
2. Symbol 1 details load into the first column. Enter or select a symbol in the second text box.  
3. To compare more than two symbols (up to four), enter additional symbols in the remaining text boxes.
