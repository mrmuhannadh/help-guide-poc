# Pro Chart

<FigureProvider>

Chart options can be accessed in two ways:

a. Click on the settings icon placed at the top right corner of the *Pro Chart* window, and select the option **Chart Options**.  
b. Right-click anywhere on the graph.

## Drawing Tools

Click on the Drawing Tool arrow, to view the various drawing tools available to use with the Pro Chart.  
Select a drawing tool from the list and draw on the Pro Chart.

Available drawing tools:
• Trend line  
• Arrow trend line  
• Horizontal line  
• Vertical line  
• Rectangle  
• Ellipse  
• Text  
• Linear regression line  
• Zig zag line  
• Arc  
• Andrews pitchfork  
• Cyclic lines
