2. Once you log in to the system click on **File** and once it's expanded you can view **New Window** icon on the top right hand corner under Market Summary Panel as displayed below,

<Figure

4. Once you chose the layout, it navigates to the next screen to choose widgets as given below, and also, once the lay out as added the user can modify the layout as wish by dragging the widget layout here and there.

<Figure
  baseName='new-window/add-widget'

6. You can add more widgets as much as you want by clicking the plus (+) icon in the widget screen

## Rename or Delete New Dashboard

1. From the **hamburger icon** on the top right corner, select the dashboard you want to manage.

<Figure
  baseName='new-window/rename-dashboard'
  alt='Rename Dashboard'
  description='Rename New Dashboard'
/>

<Figure
  baseName='new-window/delete-dashboard'
  alt='Delete Dashboard'
  description='Delete New Dashboard'
/>

2. If you choose Rename Dashboard, it allows to rename the dashboard
3. If you choose Delete Dashboard, it prompts a confirmation message dialogue box as given below
4. Once you click Yes, it deletes the dashboard and otherwise the dashboard doesn't delete

<Figure
