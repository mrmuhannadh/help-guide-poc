# Order Book Calculator

Window invoking options:

1. Tools → Order Book Calculator  
2. Right-click a symbol → Order Book Calculator

**STEPS**

1. Click on the **Customer** and select a customer  
2. Click on the **Symbol** search text box and select a symbol.  
3. Select an **Action**.  
4. Select the **Target Type**.  
5. Enter the **By Value** amount.  
6. As you type, the *Order Book Calculator* will compute details and display below, as in *Figure 1*.
