# STEBandBot

SYNTAX STEBandBot( DATAARRAY, PERIODS, ERRORS )

This calculates the value of the bottom Standard Error Band of the specified DATAARRAY. The result is shifted downward by the number of standard errors specified by ERRORS.

Eg: STEBandBot('close',5,0.01);
