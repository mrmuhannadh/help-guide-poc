# ValueWhen

SYNTAX ValueWhen ( Nth, EXPRESSION, DATAARRAY )

This looks at all the data in the chart and evaluates when the EXPRESSION was true. Then starting from the most recent, it counts back Nth times and reports the value of DATAARRAY.

Eg: ValueWhen(1,'close > 20','close')
