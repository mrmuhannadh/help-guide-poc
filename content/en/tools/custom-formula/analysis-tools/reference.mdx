# Reference

SYNTAX REF(DATAARRAY, PERIODS)

This returns the value of DATAARRAY on a previous or subsequent period. The time to be accessed is expressed by PERIODS. A negative number looks back in time while a positive number looks into the future.

Eg: REF('close',5)

**Note:**\
REF Only supports the below values mentioned in the table.

If a script needs history data, it should define the variable with the key ‘Period’ or use ‘period’ as the variable.

Eg:
```jsx
jawPeriod = input(12);
period = input(20);

---------------------------

myZ = ZigZag(close,3,percentage,zigzag);

assignValue('myZ', myZ);

out = myZ < REF('myZ',-2);
```
