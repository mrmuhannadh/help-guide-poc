# Highest Since Bars

SYNTAX HighestSinceBars( Nth, EXPRESSION, DATAARRAY )

This function looks at all the data available. It then evaluates the condition detailed in EXPRESSION. Afterward, it counts back from the most recent point of data till it finds the Nth number of times the EXPRESSION was true. From that point, it looks forward at DATAARRAY and finds the highest value and. The result of these calculations it the number of periods that have passed since this highest value.

Eg:

```jsx
a1 = MVSimple(9,close,MA);

a2 = MVSimple(10,close,MA);

out = HighestSinceBars(a1, '>', a2, 'close', 1);
```
