# HHV

SYNTAX HHV( DATAARRAY, PERIODS )

Calculates the highest value of the DATAARRAY from the most recent PERIODS number of records. The calculation includes the current period.

Eg:

```jsx
HHV('close', 5)

-------------------------------------

a1 = MVSimple(9,close,MA);

out = HHV(a1, 5);
```
