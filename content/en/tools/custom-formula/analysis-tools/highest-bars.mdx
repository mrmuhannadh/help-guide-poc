# Highest Bars

SYNTAX HighestBars( DATAARRAY )

This function reads the DATAARRAY and returns the number of periods that have past since its highest value.

Eg: HighestBarsv('close')

```jsx
a1 = MVSimple(9,close,MA);

out = HighestBars(a1);
```
