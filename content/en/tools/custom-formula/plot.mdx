# Plot

Plotting the result in the chart with drawing options.

Eg:  
* x = Open  
* y = Low  
* plot(x)  
* plot(y)

Further, we can use **FillRegion** option to plot and fill colour.

```jsx
lineA = Open;
lineB = Low;

plot(lineA);
plot(lineB);

FillRegion(lineA > lineB, lineA, lineB);
```
