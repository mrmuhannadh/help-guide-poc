# Daily Market Summary Report

View the Daily Market Summary Report in this window. This report will list the following sections:

- Market Information
- Market / Sector Summary
- Index Summary
- Top Gainers
- Top Losers
- Most Active By Volume
- Most Active By Trades

Window invoking options:

Tools → Daily Market Summary report
