# Trade Analysis Report

View the Trades Analysis Report in this window. This report will list the following sections:

- Top 25 Trades by Volume
- Top 25 Trades by Value
- Largest Trade for each Stock by Volume
- Largest Trade for each Stock by Value
- Turnover Breakdown

Window invoking options:

Tools > Trade Analysis Report
